# Phase II — отчёт

Ветка `feature/phase-2-match-intelligence` (от `feature/faceit-intelligence-mvp`, в `main` не сливалась).

## Важное ограничение окружения разработки
В облачном окружении, где шла разработка, **не было FACEIT_API_KEY и сетевого доступа к open.faceit.com,
steamcommunity.com и accounts.faceit.com**. Поэтому все проверки шли через mock FACEIT HTTP-сервер с симулированным
миром (тот же HTTP-клиент, пути, пагинация и авторизация, что и в проде) и подменённые ответы Steam/FACEIT OAuth.
Реальный API нужно проверить у себя: `make live-check NICK=… ROOM=…`.

## Fully implemented and verified (автотесты + браузерный E2E против mock-стека)
* Синтетический режим убран из UI: нет демо-аккаунтов/наборов; без ключа — явная ошибка 503, а не fixtures.
* Аккаунты: серверные сессии, CSRF, ротация, истечение, rate limiting, привязка Steam/FACEIT с защитой от захвата,
  отвязка, настройки, история анализов (тесты `test_auth.py`, E2E).
* Match Scout: разбор ссылки на комнату, сбор данных по 10 игрокам, баланс команд (Elo-ожидание + факторы),
  Elo-распределение, карточки угроз, роли, связки, риск-профили с объяснениями и альтернативами, нестабильность,
  типизированный брифинг с доказательствами, обратная связь по выводам.
* Тактика из демок: позиции и дуэли извлекаются при загрузке демки, профили с уровнями доказательности; без демок —
  честное «нет данных». Радар-трансформации проверены визуально: точки реальной демки ложатся на проходимые зоны Mirage.
* Прогнозы: неизменяемый снимок до матча, проверка результата, Brier/log loss/калибровка, полезность сигналов, отзывы отдельно.
* Коучинг: недельные сводки, предложения только из измеренных слабых мест, цели с замороженной базой, ошибки из демок.
* Существующая аналитика игрока и разбор демок продолжают работать (регрессионные тесты этапа 1 проходят).

## Implemented but not live-verified
* Реальный FACEIT Data API: форматы `/players/{id}`, `/players/{id}/stats/cs2`, `/players/{id}/games/cs2/stats`,
  поиск по `game_player_id` реализованы по документированным/известным форматам и обработаны защитно, но не
  проверялись на живых ответах — для этого `scripts/faceit_live_check.py`.
* Sign in with Steam (OpenID 2.0) — полный поток реализован, проверен на подменённых ответах Steam.
* Sign in with FACEIT (OAuth2 + PKCE) — поток реализован; эндпоинты по умолчанию взяты из конфигурации FACEIT Connect,
  они настраиваются через `.env`. Нужны client id/secret.
* Риск-модель на реальных лобби: частота срабатываний измерена только на симуляции.

## Partially implemented
* Автоопределение активного матча: Data API не даёт «текущий матч»; проверяется последняя запись истории, иначе — честное
  сообщение и вставка ссылки.
* Группировка callout'ов в A/B/Mid курирована для Mirage, Dust2, Inferno, Ancient, Anubis; на других картах выводы опираются
  на сами callout'ы.
* Оценка «опыта аккаунтов» соперников — по возрасту аккаунта FACEIT и числу матчей CS2; история Elo соперников недоступна.

## Blocked by external access
* Ключ FACEIT и сеть к FACEIT/Steam в облачном окружении; client id/secret FACEIT Connect.
