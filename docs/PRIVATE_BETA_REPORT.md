# Private Beta Readiness — отчёт

Принцип этапа: надёжность важнее функций, проверка важнее заявлений. Новых крупных функций нет, архитектура та же.
Каждый исправленный дефект сначала воспроизведён, затем закрыт регрессионным тестом.

## NOT LIVE VERIFIED (в облаке недоступно)
* **Настоящий FACEIT Data API** — ключа в облаке нет. Проверка: `make live-check NICK=ваш_ник ROOM=ссылка`.
* **Вход через Steam** (реальный steamcommunity.com) — покрыт тестами с подменёнными ответами.
* **Вход через FACEIT OAuth** — реальный вход не выполнялся; не заявляется как подтверждённый.
* **Настоящие демки FACEIT** — проверено на примере CS2-демки из репозитория и синтетических архивах.
* **Лаунчер Windows** — Windows/PowerShell в облаке нет; скрипты проверены только ревью.
* **Tailscale Serve** — только документация, ничего не запускалось.

## Открытые вопросы
| Приоритет | Вопрос |
|---|---|
| P1 | Пройти живые проверки выше (FACEIT API, Steam, при необходимости FACEIT OAuth, лаунчер Windows) до приглашения друзей |
| P2 | Пауза при 429 и лимиты входа хранятся в памяти: после перезапуска приложение один раз снова спросит FACEIT |
| P2 | Трекинг Elo работает, только пока приложение запущено (автозапуска нет намеренно) — в истории будут пропуски |
| P2 | Разведка и разбор демок — в процессе приложения; перезапуск прерывает их (явно помечаются, можно повторить) |
| P3 | История анализов может получить дубль при двух одновременных одинаковых запросах (косметика) |
| P3 | Резервное копирование — вручную (скопировать папку данных) |
| P3 | Тактические выводы точнеют только с загруженными демками; на малой выборке помечены как ориентировочные |

## Готовность
**Готово к закрытой бете для нескольких доверенных пользователей** на одном компьютере (localhost) или через Tailscale
Serve внутри tailnet — **после** живой проверки ключа FACEIT, входа через Steam и запуска на Windows. Не предназначено для
публичного размещения в интернете.
