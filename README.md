# FACEIT Intelligence

Персональная аналитическая платформа для CS2 на FACEIT. Отвечает на четыре вопроса:

| | Вопрос | Где в приложении |
|---|---|---|
| **BEFORE** | С кем я играю? Насколько сильны команды, кто главная угроза, какие связки, есть ли необычные профили? | **Разведка** (Match Scout) — ссылка на комнату → брифинг по 10 игрокам |
| **PLAY** | Что важно знать по ходу? Где соперники обычно стоят, какие зоны слабее? | Тактическая карта и тактические пункты брифинга (из разобранных демок) |
| **AFTER** | Что произошло? Совпал ли прогноз? | Снимок прогноза + результат, страница **Прогнозы** |
| **IMPROVE** | Что мешает расти? | **Коуч**: недельные сводки, цели с базовым уровнем, повторяющиеся ошибки из демок |

Плюс аналитика игрока (форма, карты, лучшие/худшие матчи, Elo, исследование матчмейкинга) и разбор демок (раунды, KAST, ADR, трейды, клатчи, хайлайты).

Источник данных — только официальный **FACEIT Data API** и **демки, которые вы загружаете**. Синтетических аккаунтов и
демо-режима в интерфейсе нет; тестовые данные живут только в автотестах.

## Запуск

**Windows 11:** `setup.cmd` один раз, затем `start.cmd` / `stop.cmd` / `status.cmd` — см. [docs/WINDOWS.md](docs/WINDOWS.md)
(только localhost, без автозапуска; доступ с телефона — по желанию через Tailscale Serve).

**macOS / Linux:** нужны Python ≥ 3.11 с [uv](https://docs.astral.sh/uv/) и Node.js ≥ 20.

```bash
cp backend/.env.example backend/.env   # впишите FACEIT_API_KEY (server-side ключ из developers.faceit.com)
make install                           # uv sync + npm install
make serve                             # API + интерфейс на http://localhost:8000
```

Разработка: `make backend` (:8000) + `make frontend` (:5173, прокси `/api`).
Необязательно: `make radars` — радары карт для тактической карты (без них карта рисуется схемой по реальным координатам).

### Вход
* **Steam** работает сразу (OpenID 2.0, секрет не нужен). После входа приложение находит ваш FACEIT-профиль по SteamID через Data API.
* **FACEIT** (FACEIT Connect, OAuth2 + PKCE): создайте приложение в FACEIT Developers, укажите redirect URI
  `${APP_BASE_URL}/api/auth/faceit/callback`, заполните `FACEIT_CLIENT_ID` / `FACEIT_CLIENT_SECRET`. Без них кнопка
  показывает «не настроен», остальное работает.
* Steam и FACEIT можно привязать к одной учётной записи в «Настройках».
* Закрытая бета: данные доступны только после входа (`REQUIRE_LOGIN=true`). `BETA_ALLOWLIST` — список SteamID64 / FACEIT
  id / ников, которым разрешён вход. `TRACKING_INTERVAL_MINUTES` — как часто сохранять реальный Elo привязанных игроков
  (0 — выключить). `DATA_DIR` — где хранить базу, кэш и демки.

### Проверка с настоящим FACEIT
```bash
make live-check NICK=ваш_ник ROOM=https://www.faceit.com/ru/cs2/room/1-…   # ROOM необязателен
```
Скрипт проходит по всем эндпоинтам, которые использует приложение, проверяет поля, на которые опираются нормализаторы, и
строит полный отчёт разведки по реальной комнате. Секреты не печатает.

## Проверки

```bash
make test        # backend pytest (77 тестов) + frontend vitest (29)
make lint        # ruff + tsc + eslint
make mock-stack  # в другом терминале: стек против MOCK FACEIT API (тестовый мир, не реальные данные)
make e2e         # браузерный E2E Phase II (Playwright): вход, разведка, прогноз→результат, настройки, коуч, демки
make e2e-beta    # самодостаточный E2E беты: экран входа, 401, разведка, перезапуск, сбой FACEIT, повтор демки, выход, телефон
make e2e-ux      # E2E интерфейса: фазы входа, медленные/сломанные/отменённые запросы, офлайн, Slow 3G, телефон
```
